# WebWelle - Professionelle Website

Eine moderne, responsive Website für WebWelle - Ihr Partner für Festpreis-Webdesign.

## 🚀 Features

- **Next.js 15** mit App Router
- **Tailwind CSS 4** für modernes Styling
- **TypeScript** für typsichere Entwicklung
- **Responsive Design** für alle Geräte
- **SEO-optimiert** mit Metadaten und Sitemap
- **Performance-optimiert** für beste Ladezeiten
- **Accessibility** mit Fokus auf Barrierefreiheit

## 📋 Sektionen

1. **Header** - Navigation mit Logo und Menü
2. **Hero** - Hauptbotschaft und Call-to-Action
3. **Produkte** - Next.js und WordPress Pakete
4. **Vorteile** - WebWelle Benefits
5. **Leistungen** - Service-Übersicht
6. **Arbeitsweise** - Prozess-Visualisierung
7. **FAQ** - Häufige Fragen
8. **CTA** - Call-to-Action Bereich
9. **Footer** - Kontakt und Links

## 🛠️ Entwicklung

```bash
# Dependencies installieren
npm install

# Entwicklungsserver starten
npm run dev

# Production Build
npm run build

# Production Server starten
npm start
```

## 📱 Responsive Breakpoints

- **Mobile**: < 768px
- **Tablet**: 768px - 1024px
- **Desktop**: > 1024px
