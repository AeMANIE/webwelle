Directus Collection: webwelle_bookings

Felder
- id (uuid, primary)
- created_at (datetime, default: now)
- status (string, enum: pending|paid|failed|cancelled)
- session_id (string, unique)  // Stripe Checkout Session ID
- package_type (string, enum: starterwelle|businesswelle|erfolgswelle|flowwelle|powerwelle|meisterwelle)
- is_monthly (boolean)
- package_price_display (string) // z.B. "139 € mtl."

Kunden & Firma (optional)
- customer_name (string, nullable)
- customer_email (string, nullable)
- customer_phone (string, nullable)
- company_name (string, nullable)
- existing_website (string, nullable)

Projekt-Infos
- target_group (json) // string[]
- design_style (string, nullable)
- design_reference_url (string, nullable)
- selected_addons (json) // [{key: string, billing: 'oneTime'|'monthly'}]
- message (text, nullable)

Technik
- raw_form_data (json) // vollständiges Formular
- stripe_metadata (json)

Indizes
- idx_status_created_at (status, created_at)
- idx_session_id (session_id)

Hinweise
- selected_addons aus Frontend: BookingForm.zusatzfunktionen + zusatzzahlung
- customer_email ist optional, Checkout darf ohne Vorab-E-Mail starten
